# Internationalization (i18n)

## Overview

Habit Forge supports 6 languages using a lightweight React Context-based i18n system.

## Supported Languages

| Code | Language | Native Name |
|------|----------|-------------|
| `en` | English | English |
| `ru` | Russian | Русский |
| `fr` | French | Français |
| `it` | Italian | Italiano |
| `ee` | Estonian | Eesti |
| `es` | Spanish | Español |

## Architecture

```
src/i18n/
├── index.ts          # Exports and useTranslation hook
├── context.tsx       # I18nProvider component
└── translations.ts   # Translation strings
```

## Usage

### In Components

```tsx
import { useTranslation } from '@/i18n';

function MyComponent() {
  const { t, language, setLanguage } = useTranslation();

  return (
    <div>
      <h1>{t.today.title}</h1>
      <p>{t.common.loading}</p>
    </div>
  );
}
```

### Translation Object Structure

```typescript
interface Translations {
```

## Adding a New Language

1. Add language code to the `Language` type in `src/types/index.ts`:
   ```typescript
   export type Language = 'en' | 'ru' | 'fr' | 'it' | 'ee' | 'es' | 'de';
   ```

2. Add translations in `src/i18n/translations.ts`:
   ```typescript
   export const translations: Record<Language, Translations> = {
     // ... existing languages
     de: {
       common: {
         loading: 'Laden...',
         // ... all keys
       },
       // ... all sections
     },
   };
   ```

3. Add language option in `src/screens/SettingsScreen/SettingsScreen.tsx`:
   ```tsx
   <option value="de">Deutsch</option>
   ```

## Language Detection

On first load:
1. Check localStorage for saved preference
2. Detect browser language via `navigator.language`
3. Fall back to English if not supported

```typescript
function detectLanguage(): Language {
  const saved = localStorage.getItem('habit-forge-language');
  if (saved && isValidLanguage(saved)) return saved;

  const browserLang = navigator.language.split('-')[0];
  if (isValidLanguage(browserLang)) return browserLang;

  return 'en';
}
```

## Persistence

Language preference is stored in localStorage:
- Key: `habit-forge-settings`
- Value: `{ language: "en" }`

Changes are immediately reflected without page reload.
